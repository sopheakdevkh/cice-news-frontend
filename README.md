# CICE News Portal

Modern web application for **CICE News (Cambodia International Communication Echo)** built with React 19, Vite, React Router, and Tailwind CSS.

## Features

- **Multi-language Support**: English (`/en`) & Chinese (`/zh`) portals.
- **English Homepage**: Featured hero story, 3-column sub-grid, 4-column category showcase, and Chinese news preview.
- **Chinese Magazine Layout**: Interactive hero carousel with automatic rotation, ranked Cambodian top news (01–05), modular 2-column news blocks, opinion columnist cards, and research reports.
- **Category Feeds**: Dynamic categorization (`/category/:slug`) with breadcrumbs, sidebar rankings, and pagination.
- **Article Reader**: Full article view (`/article/:slug`) with category badges, author/date metadata, social sharing, and sequential previous/next navigation.
- **Search System**: Search page with query filtering and matching results.
- **Ad Integrations**: Responsive banner slots (Leaderboard, Sidebar, In-feed, and Promo).

## Getting Started

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
